## Configuration

The config file is `BepInEx/config/hs.hs_modstub.cfg`. A server admin can lock it with "Lock Configuration": the server's values then apply to every player.

## Installation

Install with a mod manager (r2modman, Thunderstore Mod Manager or Gale), or put `HS_ModStub.dll` in `BepInEx/plugins`.
The mod is required on both the server and every client.
